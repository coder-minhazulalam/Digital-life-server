# Digital Life Lessons — Server Backend

Digital Life Lessons backend server built with Express.js, MongoDB native driver, Better Auth, and Stripe payment processing.

## 🚀 Key Features
- Better Auth authentication (email/password & Google)
- Role-based Access Control (User / Admin)
- REST APIs for Life Lessons, Comments, Favorites, and Reports
- Stripe checkout integration for Premium plan (৳1500 lifetime)
- Admin moderation endpoints (Flagged lessons, user roles, featured lessons)

## 📦 Tech Stack
- Express.js 5
- MongoDB Node.js Driver
- Better Auth
- Stripe
- dotenv, cors
